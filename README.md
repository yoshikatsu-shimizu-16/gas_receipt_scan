# 領収書・請求書 AI抽出・管理システム (gas_receipt_scan)

このプロジェクトは、Google Apps Script (GAS) と Gemini API を活用して、領収書や請求書から「利用者名・日付・摘要・金額」を自動抽出し、管理を効率化する業務アプリケーション・プロトタイプ（MVP版）です。

## 🌟 主な機能
1. **AI自動抽出**: 既定では `gemini-2.5-flash-lite` を使用し、レートリミットを考慮した高速なデータ抽出を実現。
2. **2ペインUI**: 左側に書類プレビュー、右側にAI抽出結果を表示。
3. **Google Drive連携**: 
   - 処理前フォルダからのファイル取得。
   - 保存時の自動リネーム（利用者名_日付_摘要）とフォルダ移動。
4. **スプレッドシート記録**: 抽出データの自動蓄積。
5. **利用者マスタ**: スプレッドシート上の `users` シートと連携した名寄せ。
6. **環境自動構築**: ボタン一つでフォルダ・スプレッドシート・スクリプトプロパティの初期設定を完了。

## 🚀 開発・セットアップ手順

### 1. Google Apps Script プロジェクトの準備
1. [Google Apps Script](https://script.google.com/) にアクセスし、新規プロジェクトを作成します。
2. 「プロジェクトの設定（歯車アイコン）」から **スクリプト ID** をコピーします。

### 2. ローカル環境からのデプロイ (clasp)
本プロジェクトは `clasp` での管理を前提としています。
1. `clasp login` でGoogleアカウントにログインします。
2. `.clasp.json` の `scriptId` フィールドに、先ほどコピーしたスクリプトIDを貼り付けます。
3. 以下のコマンドを実行して、コードをGAS側にプッシュします。
   ```bash
   clasp push
   ```

### 3. APIキーの設定
1. [Google AI Studio](https://aistudio.google.com/) で Gemini API キーを取得します。
2. GASエディタの「プロジェクトの設定」>「スクリプト プロパティ」に以下を追加します。
   - **プロパティ名**: `GEMINI_API_KEY`
   - **値**: 取得したAPIキー
3. モデルを変更したい場合のみ、同じくスクリプトプロパティに `GEMINI_MODEL` を追加します。
   - 未設定時の既定値: `gemini-2.5-flash-lite`

### 4. ウェブアプリの公開
1. GASエディタの「デプロイ」>「新しいデプロイ」をクリック。
2. 種類を「ウェブアプリ」に設定。
3. **次のユーザーとして実行**: `自分`
4. **アクセスできるユーザー**: `全員`
5. 発行されたURLにアクセスします。

https://script.google.com/macros/s/AKfycbyrYl_BjVUyNHfsLS_ZdWsnpMsLzzI1vH1bFbaAP_GdrCGjT0xrWOh3fgvY0BcqmbVujQ/exec

### 5. デモ環境の自動構築
1. アプリ画面の「**環境設定**」タブを開きます。
2. 「**🚀 デモ環境を自動作成**」ボタンをクリックします。
3. これにより、Drive内に「領収書AI抽出システム（デモ用）」フォルダ一式とスプレッドシートが作成され、自動的にIDが紐付けられます。

## 💡 利用方法
1. 作成された `01_処理前 (Input)` フォルダに、領収書や請求書をアップロードします。
2. アプリの「AI抽出・確認」タブで「**Drive同期**」を実行します。
3. 抽出結果を確認・修正し、「**確定して保存・移動**」をクリックします。

## 🛠 開発者向け
- **clasp**: ローカルでの開発とバージョン管理を推奨します。
- **SPA構成**: `Prototype.html` は CSS/JS を含むシングルページアプリケーションとして構成されています。
- **Rate Limit**: 既定モデルに `gemini-2.5-flash-lite` を採用しており、連続処理時の安定性を高めています。
